# Questions fréquentes

### Qui peut rejoindre Omada for eureka ?
Toute personne étudiante ou passionnée d'informatique, quel que soit son niveau.

### Faut-il savoir utiliser GitHub pour participer ?
Non. Tu peux commencer sur Discord. Un atelier Git et GitHub est prévu, et le [guide GitHub](docs/github-guide.md) explique les bases.

### Comment proposer une ressource ?
Ouvre une Issue « Proposer une ressource » dans [resources](https://github.com/Omada-for-eureka/resources/issues/new/choose) ou partage-la dans `#partage-de-ressources` sur Discord.

### Comment proposer une activité ?
Décris ton idée dans `#propositions-activites` ou ouvre une Issue dans [activities](https://github.com/Omada-for-eureka/activities/issues/new/choose). Voir [docs/activity-workflow.md](docs/activity-workflow.md).

### Comment proposer un projet ?
Ouvre une Issue « Proposer un projet » dans [community-projects](https://github.com/Omada-for-eureka/community-projects/issues/new/choose).

### Dois-je être administrateur pour contribuer ?
Non. Les Issues et Pull Requests sont ouvertes à tous.

### Comment devenir mainteneur ou responsable ?
En contribuant régulièrement et en te proposant. Les rôles sont revus tous les trois mois.

### Où signaler un comportement inapproprié ?
Auprès d'un modérateur en message privé ou à [EMAIL_CONTACT]. Voir le [code de conduite](CODE_OF_CONDUCT.md).

### Où signaler une faille ou un secret publié par erreur ?
Voir [SECURITY.md](SECURITY.md). Jamais dans une Issue publique.
