# Prise de décision

## Types de décisions

| Type | Exemples | Qui décide | Comment |
| --- | --- | --- | --- |
| Courante | Ajouter une ressource, corriger un lien | Mainteneur du dépôt | Relecture de PR |
| Opérationnelle | Planifier une activité, créer un salon | Responsable concerné + coordination | Discussion Discord ou Issue |
| Structurante | Nouveau dépôt, nouveau rôle, nouvel outil/bot | Fondateurs après consultation | Issue `proposal` + délai de commentaires |
| Majeure | Mission, nom, règles, gouvernance | Fondateurs | Issue `proposal`, consultation de la communauté, PR dans ce dépôt |

## Processus pour une décision structurante ou majeure

1. Ouvrir une Issue avec le modèle **Proposition** dans `community-handbook`.
2. Décrire le contexte, la proposition, les alternatives et l'impact.
3. Laisser un délai de commentaires (indicatif : 7 jours).
4. Les fondateurs tranchent en tenant compte des retours.
5. La décision est consignée dans l'Issue, puis appliquée par Pull Request.
6. Un résumé est publié dans `#annonces` si elle concerne les membres.
