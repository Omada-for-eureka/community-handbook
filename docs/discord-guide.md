# Guide Discord

Discord est le lieu de discussion et d'animation. Les documents de référence et livrables durables sont conservés sur GitHub.

Serveur : Omada for eureka — invitation : [DISCORD_INVITE]

## Catégories et salons

### `00・ACCUEIL`
| Salon | Usage | Écriture |
| --- | --- | --- |
| `bienvenue` | Message d'accueil | Responsables |
| `reglement` | Règles | Responsables |
| `annonces` | Annonces officielles | Responsables |
| `presentations` | Se présenter | Membres |
| `comment-participer` | Mode d'emploi | Responsables |

### `01・COMMUNAUTE`
`general`, `entraide`, `discussions-tech`, `idees-et-suggestions`, `showcase`

### `02・RESSOURCES`
`partage-de-ressources`, `outils-et-logiciels`, `plugins-et-extensions`, `sites-et-plateformes`, `github-updates` (notifications GitHub filtrées)

### `03・APPRENTISSAGE`
`programmation`, `web-dev`, `mobile-dev`, `cybersecurite`, `ia-et-data`, `devops-cloud`, `bases-de-donnees`

### `04・ACTIVITES`
`calendrier`, `challenges`, `ateliers`, `hackathons`, `projets-communautaires`, `propositions-activites`

### `05・VOCAL`
`General`, `Salle-de-travail`, `Pair-programming`, `Ateliers-et-formations`, `Reunions-organisateurs`

### `06・EQUIPE` (accès restreint)
`coordination`, `moderation`, `organisation-activites`, `maintenance-github`, `reunions-equipe` (vocal)

Ne pas créer trop de salons au départ : ajouter ceux qui manquent quand le besoin apparaît.

## Rôles

1. `Fondateur`
2. `Administrateur`
3. `Modérateur`
4. `Responsable d'activité`
5. `Mainteneur`
6. `Responsable de domaine`
7. `Mentor`
8. `Contributeur`
9. `Membre`
10. `Nouveau membre` (si nécessaire)
11. Rôles de domaine facultatifs : `Python`, `Web`, `Cybersecurity`, `AI & Data`, `DevOps`…

Les rôles de domaine identifient les centres d'intérêt et ne donnent aucune permission d'administration.

## Permissions

- `@everyone` : salons d'accueil uniquement.
- `Nouveau membre` : présentations et salons de démarrage.
- `Membre` : salons communautaires.
- `Contributeur`, `Mentor` : rôles de reconnaissance, sans privilège global.
- `Responsable d'activité` : publication dans les salons d'activités.
- `Mainteneur` : accès à `#maintenance-github`.
- `Modérateur` : permissions de modération nécessaires.
- `Administrateur` : administration du serveur selon ses responsabilités.
- `Fondateur` : gestion complète, réservée aux personnes indispensables.

## Sécurité

- Niveau de vérification adapté et protections anti-spam (AutoMod) activés.
- Invitations et intégrations limitées aux responsables autorisés.
- Ne jamais donner `Administrator` à un bot sans nécessité démontrée.
- Ne jamais demander de mot de passe ou de clé API dans un salon.

## Messages prêts à publier

### `#bienvenue`
```text
Bienvenue sur Omada for eureka !

Nous sommes une communauté d'étudiants et passionnés d'informatique.
Notre objectif est d'apprendre ensemble, partager des ressources,
réaliser des projets et organiser des activités techniques.

Pour commencer :
1. Lis le règlement.
2. Présente-toi dans #presentations.
3. Consulte #comment-participer.
4. Découvre notre organisation GitHub : https://github.com/Omada-for-eureka
5. Participe aux discussions et propose tes idées.

Tu peux contribuer quel que soit ton niveau.
Bienvenue parmi nous !
```

### `#reglement`
```text
RÈGLEMENT DE LA COMMUNAUTÉ

1. Respecter tous les membres.
2. Ne pas harceler, discriminer, menacer ou insulter.
3. Éviter le spam et la publicité non autorisée.
4. Publier dans les salons appropriés.
5. Respecter les droits d'auteur et les licences.
6. Ne jamais partager de données personnelles ou de secrets.
7. Ne pas diffuser de logiciels malveillants ou de contenus dangereux.
8. Accepter les désaccords techniques avec respect.
9. Respecter les décisions de modération et utiliser les voies de recours.
10. Contribuer à maintenir un environnement accueillant.

Code de conduite complet : https://github.com/Omada-for-eureka/community-handbook/blob/main/CODE_OF_CONDUCT.md
Les signalements peuvent être adressés à l'équipe de modération.
```

### `#comment-participer`
```text
COMMENT PARTICIPER ?

Partager une ressource :
- Présente-la dans #partage-de-ressources.
- Propose son ajout sur GitHub : https://github.com/Omada-for-eureka/resources

Proposer une activité :
- Décris ton idée dans #propositions-activites.
- Un responsable peut t'aider à la mettre en place.

Participer à un projet :
- Consulte https://github.com/Omada-for-eureka/community-projects
- Rejoins une équipe ou propose ton aide.

Contribuer à la documentation :
- Consulte le guide CONTRIBUTING du dépôt concerné.
- Ouvre une Issue ou une Pull Request.

Tu n'as pas besoin d'être administrateur pour contribuer.
```
