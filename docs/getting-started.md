# Bien démarrer dans Omada for eureka

Bienvenue ! Voici les étapes pour trouver ta place.

## 1. Rejoindre les espaces

- **Discord :** https://discord.gg/GzT3tE8MHD — discussions, entraide, annonces.
- **GitHub :** https://github.com/Omada-for-eureka — ressources, projets, activités, règles.

## 2. Premiers pas sur Discord

1. Lire `#reglement`.
2. Te présenter dans `#presentations` (prénom ou pseudo, domaines d'intérêt, niveau, ce que tu veux apprendre).
3. Lire `#comment-participer`.
4. Choisir tes rôles de domaine (Python, Web, Cybersecurity, AI & Data, DevOps…).

Détails : [discord-guide.md](discord-guide.md).

## 3. Premiers pas sur GitHub

1. Créer un compte GitHub si tu n'en as pas.
2. Activer l'authentification à deux facteurs (2FA).
3. Lire le [guide GitHub](github-guide.md).
4. Chercher une Issue `good first issue`.

## 4. Trouver comment contribuer

| Je veux… | Où aller |
| --- | --- |
| Poser une question | `#entraide` |
| Partager une ressource | `#partage-de-ressources` puis [resources](https://github.com/Omada-for-eureka/resources) |
| Proposer une activité | `#propositions-activites` — voir [activity-workflow.md](activity-workflow.md) |
| Rejoindre un projet | [community-projects](https://github.com/Omada-for-eureka/community-projects) |
| Montrer ce que j'ai fait | `#showcase` |

## 5. Les règles essentielles

- Respect et bienveillance ([code de conduite](../CODE_OF_CONDUCT.md)).
- Jamais de secrets ni de données personnelles.
- Les connaissances durables vont sur GitHub, pas seulement sur Discord.
