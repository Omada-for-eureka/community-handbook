# Processus de modération

## Étapes

1. Recevoir un signalement (message privé, email, signalement Discord).
2. Vérifier les faits sans tirer de conclusion hâtive.
3. Prendre une mesure proportionnée si nécessaire.
4. Conserver uniquement les informations nécessaires.
5. Informer les personnes concernées dans la mesure appropriée.
6. Escalader les incidents graves aux administrateurs.
7. Permettre un recours ou une demande de réexamen.
8. Documenter la procédure sans exposer publiquement les personnes.

## Mesures selon la gravité

| Niveau | Mesure |
| --- | --- |
| 1 | Rappel des règles |
| 2 | Demande de correction |
| 3 | Suppression d'un contenu problématique |
| 4 | Avertissement |
| 5 | Restriction temporaire (timeout) |
| 6 | Exclusion — dernier recours ou gravité particulière |

## Recours

La personne concernée peut demander un réexamen à un administrateur qui n'a pas pris la décision initiale.

## Confidentialité

- Les échanges de modération restent dans `#moderation` (accès restreint).
- Aucun signalement ni donnée personnelle n'est publié sur GitHub.
- Les signalements ne sont pas conservés indéfiniment (durée : [À DÉFINIR par les fondateurs]).
